# Nexora

Nexora is a multi-store e-commerce engine for creating professional online stores for small businesses.

## Current phase

Foundation only.

Included:
- Next.js App Router
- TypeScript
- Tailwind CSS
- ESLint
- Scalable multi-store folder structure

Not included yet:
- Database
- Authentication
- Products
- Orders
- Payments
- Dashboard functionality

## Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
